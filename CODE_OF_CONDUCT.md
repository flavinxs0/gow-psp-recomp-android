# Código de conduta / Code of conduct

## 🇧🇷 Português

Todas as pessoas participantes devem ser respeitosas e construtivas. Não serão tolerados assédio, insultos, ataques pessoais, discriminação ou publicação de conteúdo protegido por direitos autorais.

Não compartilhe arquivos do jogo em Issues, Pull Requests ou discussões. Remova informações pessoais de logs antes de publicá-los.

Relate problemas de conduta de forma privada ao responsável pelo projeto pelo GitHub. O conteúdo que violar estas regras poderá ser removido e participantes poderão perder o acesso à comunidade.

Este projeto segue os princípios do [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## 🇺🇸 English

Everyone participating in this project is expected to be respectful and constructive. Harassment, insults, personal attacks, discrimination, or sharing copyrighted content are not allowed.

Do not share game files in Issues, Pull Requests, or discussions. Remove personal information from logs before posting them.

Report conduct concerns privately to the project maintainer through GitHub. Content that violates these rules may be removed, and participants may lose access to the community.

This project follows the principles of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
